# Linha do tempo — Festival Hercule Florence de Fotografia

Linha do tempo das 16 edições do Festival Hercule Florence de Fotografia, em
Campinas-SP, de 2007 a 2026, com fotos e recortes de imprensa de cada ano.

- **Página:** `index.html` (ver ao vivo via GitHub Pages)
- **Curadoria e fontes:** [notas-curadoria.md](notas-curadoria.md)

Projeto da [Communitas](https://communitas.com.br) para o Instituto Hercule Florence.
